# Tech Tronics – Blog Platform

A modern blog platform interface built with Next.js and TypeScript, focused on delivering a clean and engaging reading experience for tech content.


## Overview

Tech Tronics is a frontend blog platform designed to organize and present articles in a structured and user-friendly way.

The project focuses on content browsing, filtering and smooth navigation between articles and categories, while maintaining a modern UI experience.


## Core Features

- Blog listing with categories  
- Single article page  
- Search and filtering system  
- Dark / light mode support  
- About page  
- Contact page  
- Responsive design    


## Tech Stack

- Next.js  
- TypeScript  
- Tailwind CSS  
- Framer Motion (if used)
